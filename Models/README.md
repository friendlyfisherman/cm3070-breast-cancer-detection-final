# Trained Models

The trained `.keras` model files are not included in this repository because of file-size constraints.

They can be reproduced by running the corresponding notebooks:

- `notebooks/01b_baseline_cnn_patient_grouped.ipynb`
- `notebooks/02_transfer_learning_vgg16.ipynb`

The independent evaluation notebook expects the trained models to be placed in this `Models` directory using the filenames:

- `baseline_cnn_patient_grouped.keras`
- `vgg16_patient_grouped.keras`
